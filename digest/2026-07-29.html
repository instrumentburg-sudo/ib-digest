Microsoft вынесла ограничения для агентов из подсказок в код

Что случилось Agent Governance Toolkit попал в суточный GitHub Trending: 46 новых звёзд за день, 5 328 всего. Репозиторий обновлён внутри нашего окна. Инструмент перехватывает вызов до выполнения и применяет правила из YAML: например, запрещает drop, delete, truncate, а отправку писем пропускает только после подтверждения. Пока это публичная предварительная версия.

Живой пример https://github.com/microsoft/agent-governance-toolkit

👉 Как применить: взять идею для Hermes — запретить необратимые команды и внешние отправки на уровне инструмента, а не надеяться на текст инструкции. Сначала проверить на одном внутреннем агенте без доступа к боевым данным.

ECC собирает полный рабочий цикл агента в один набор

Что случилось ECC набрал 636 звёзд за сутки в GitHub Trending и обновился внутри окна. В наборе заявлены 67 агентов, 281 навык, 94 команды, память, проверки безопасности и цикл план → тест → реализация → проверка → подтверждение → память. Поддерживаются Claude Code, Codex и другие среды.

Живой пример https://github.com/affaan-m/ECC

👉 Как применить: целиком не ставить — он дублирует значительную часть нашей системы. Разобрать три узких блока: AgentShield, проверку изменений из нового контекста и автоматическое превращение повторяемых решений в навыки.

Preflight ставит локальный шлюз перед публикацией агентского кода

Что случилось свежая публикация в X показала Preflight — новый локальный инструмент, который читает git diff, запускает проверки проекта, сводит несколько модельных оценок и возвращает один вердикт. Запуск без регистрации: npx @khosla/preflight. Репозиторий пока крошечный — 2 звезды, поэтому это именно опытный образец, а не готовый стандарт.

Живой пример https://x.com/geetkhosla/status/2082212131018064280

👉 Как применить: прогнать на одном изменении калькулятора или сводки и сравнить с нашим текущим этапом проверки перед коммитом. Если ловит реальные ошибки без лишнего шума — добавить как второй независимый барьер.

Колонки доски запускают разные стадии Claude Code

Что случилось свежий кейс в X показывает доску, где перемещение задачи автоматически запускает отдельные стадии: планирование, проверку кода и тесты. Это не новый продукт, а конкретный шаблон управления агентами через состояние задачи.

Живой пример https://x.com/ag_llama/status/2082232135508005353

👉 Как применить: повторить на нашей доске задач только для безопасных стадий — «готово к плану», «на проверке», «тесты». Публикацию и необратимые действия оставить за ручным подтверждением.
