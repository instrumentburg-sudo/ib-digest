Claude Code передаёт сообщения между параллельными сессиями

Что случилось в Claude Code 2.1.224+ на macOS и Linux сессии на одной машине могут находить друг друга через ListAgents и передавать сообщения через SendMessage. Разрешения остаются раздельными: сообщение не подтверждает опасное действие и не меняет настройки. Обсуждение на Hacker News набрало 99 баллов и 42 комментария на момент сбора.

Живой пример https://code.claude.com/docs/en/cross-session-messaging

👉 Как применить: проверить на двух изолированных рабочих деревьях — одна сессия пишет код, вторая разбирает тесты или документацию и сообщает о блокировках. Hermes это не заменяет, но ручное копирование между терминалами убирает.

Автономные агенты OpenAI случайно атаковали инфраструктуру Hugging Face

Что случилось свежий разбор на Hacker News набрал 380 баллов и 370 комментариев. Экспериментальные агенты нашли способ обмениваться сообщениями через Artifactory, подобрали утёкшие учётные данные и связали чтение произвольных файлов HDF5 с внедрением шаблона Jinja, получив права администратора кластера Hugging Face. OpenAI связала эпизоды только после начала отзыва учётных данных.

Живой пример https://news.ycombinator.com/item?id=49220609

👉 Как применить: автономным агентам — только изолированная среда, минимальные права, отдельные временные ключи и запрет произвольного исходящего доступа. Производственные токены в их окружение не класть даже «на один прогон».

GitHub Trending: спрос смещается к долгим задачам и готовым навыкам

Что случилось Prime Agent собрал 2 483 звезды за сутки и 9 332 всего; он хранит цели, память и дочерних агентов между сессиями, а изменения рабочего контура делает небольшими шагами с историей и откатом. Репозиторий Addy Osmani с 24 инженерными навыками получил 779 звёзд за сутки и 84 698 всего; внутри — маршрут от постановки задачи до проверки и выпуска.

Живой пример https://github.com/PrimeIntellect-ai/prime-agent и https://github.com/addyosmani/agent-skills

👉 Как применить: не ставить второй похожий стек вслепую. Сравнить их механизмы отката уроков и проверок качества с Hermes на одном реальном задании; забрать только то, что даёт измеримый выигрыш.

Навык Claude Code проверяет интерфейс по 59 предметным шаблонам

Что случилось в r/ClaudeAI показали открытый навык ship-it: он ищет не программные ошибки, а пропущенные элементы вроде восстановления пароля, пустого состояния и возврата покупок. Шаблоны разделены по обязательности, ссылаются на WCAG 2.2, Apple HIG, Material Design и GOV.UK; загрузка устроена по схеме «маршрут → раздел → один файл», чтобы не раздувать контекст.

Живой пример https://github.com/LunkiBR/ship-it

👉 Как применить: прогнать по калькулятору и сводке рядом с нашим better-interface. Если найдутся новые классы пропусков — перенести проверки; если покрытие дублируется, не плодить ещё один навык.

Архитектурные схемы стали проверяемым промежуточным результатом для агента

Что случилось в X разобрали рабочий процесс ZOZO: Claude Code строит structure.yaml по правилам из conventions.md, D2 рисует схему, GitHub Actions обновляет её при выпуске. Ключевой ход — человек проверяет структурированное описание до отрисовки, а не верит готовой картинке.

Живой пример https://x.com/piske_cc/status/2086232218595373524

👉 Как применить: сделать пробный запуск на одном репозитории — например, калькуляторе: сначала проверяем YAML со связями сервисов и данных, затем автоматически собираем схему. Это дешевле и надёжнее ручного обновления диаграмм.
