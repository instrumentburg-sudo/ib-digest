🔧 OpenClaw v2026.9.4:

  • Появился безопасный автоматический откат совместимых неудачных обновлений: система сохраняет прежний пакет, конфигурацию и службу, затем проверяет восстановленный шлюз. Миграции базы по-прежнему требуют заранее проверенной резервной копии.[1]

🤖 Claude Code v2.1.268:

  • Исправлены утечки секретов в сообщениях об ошибках плагинов и MCP, обход правил доступа через символьные ссылки, зависание WebFetch и загрузка инструментов из недоверенной папки агентом с совпадающим именем.[2]
  • Команды управления плагинами получили JSON-вывод; плагины теперь применяются без /reload-plugins. Исправлены высокая загрузка процессора в простаивающих сессиях и поломка сторонних Anthropic-совместимых шлюзов после версии 2.1.265.[2]
  • Для нас: версия полезная и по безопасности, и по стабильности. После обновления проверить claude plugin list --json, MCP-конфигурации и один длинный фоновый сеанс.

OpenAI открыл Agents API

Что случилось приложения получили управляемую оболочку Codex с постоянными сессиями, сжатием контекста, восстановлением, песочницей, MCP и параллельными подагентами. Среду исполнения можно оставить у OpenAI или подключить свою.[3] На Hacker News тема набрала 206 баллов и 123 комментария примерно за 10 часов.[7]

Живой пример https://developers.openai.com/showcase/agents-api-github-issues

👉 Как применить: не переносить текущие процессы сразу. Взять один безопасный сценарий — разбор GitHub-задачи в отдельной песочнице — и сравнить с Hermes по цене, времени и доле задач, дошедших до проверяемого результата.

Cognition выпустила SWE-2

Что случилось новый агентный кодовый модельный ряд показал 50,0% на FrontierCode 1.1 Main и 73,0% на DeepSWE 1.1. Cognition заявляет цену на 64% ниже Fable 5.1 при отставании менее одного процентного пункта на FrontierCode.[4]

Живой пример https://cognition.com/blog/swe-2

👉 Как применить: цифры вендора не принимать на веру. Если модель появится в доступном нам шлюзе, дать ей 10 реальных задач из InstrumentBurg и сравнить с Codex/Claude по успешным тестам и стоимости, а не по красивому бенчмарку.

TeamAI CLI вышел в дневные лидеры GitHub

Что случилось репозиторий Tencent набрал 841 звезду за сутки в GitHub Trending.[8] Инструмент хранит навыки, правила, MCP и знания команды в общем Git-репозитории и раскладывает их по Claude Code, Codex, Cursor и другим агентам; изменения проходят через ветку и проверку.[5]

Живой пример https://github.com/Tencent/teamai-cli

👉 Как применить: это прямой кандидат на устранение ручного дублирования правил между Hermes, Claude и Codex. Проверять только в отдельном тестовом репозитории: инструмент внедряет свои хуки и ресурсы, поэтому подключать его к рабочим профилям без аудита нельзя.

llmfit подбирает локальную модель под реальное железо

Что случилось утилита из сегодняшнего GitHub Trending определяет CPU, RAM, GPU/VRAM и ранжирует модели по вместимости, скорости, качеству и контексту. Есть замер фактических токенов в секунду и JSON API для автоматизации.[6][8]
