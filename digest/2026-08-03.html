Qwen3.8-Max показали на длинной автономной разработке

Что случилось Qwen выпустила Qwen3.8-Max — 2,4 трлн параметров, из которых 95 млрд активны; открытые веса обещаны на следующей неделе. Живой пример [oh-my-cli — полный след автономной разработки](https://github.com/qwen-code-dev-bot/oh-my-cli) · [анонс Qwen](https://qwen.ai/blog?id=qwen3.8) · [обсуждение HN](https://news.ycombinator.com/item?id=49150470)

👉 Как применить: после появления API или весов прогнать один изолированный длинный заказ на копии репозитория HQ и сравнить с Claude/Codex по трём метрикам: дошёл ли до готового результата, сколько потребовал ручных исправлений, сколько стоил. В рабочие репозитории без такой проверки не пускать.

TencentDB Agent Memory — память с возвратом к первоисточнику

Что случилось репозиторий набрал 602 звезды за сутки и 11 374 всего. Он раскладывает память агента по слоям: исходные диалоги и журналы → факты → сценарии → профиль, а длинные промежуточные результаты выносит из контекста с возможностью провалиться обратно к доказательству. Авторы заявляют до 61,38% экономии токенов и рост успешности WideSearch с 33% до 50%; это их собственный тест.

Живой пример [TencentDB-Agent-Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory)

👉 Как применить: взять один длинный процесс TenderPlan и сравнить с текущей памятью Hermes: расход токенов, число повторных запросов контекста, доля завершённых шагов. Решение о внедрении — только после проверки приватности и воспроизводимости заявленных цифр.

OpenWork быстро растёт как открытая альтернатива Claude Cowork

Что случилось OpenWork поднялся в GitHub Trending — 280 звёзд за сутки, 20 478 всего; основная ветка обновлялась около восьми часов назад. Это бесплатное настольное приложение для обмена рабочими сценариями AI: отдельное рабочее пространство необязательно, а один MCP позволяет использовать назначенные навыки, подключения и сервисы из Claude Code, Codex, Cursor и других совместимых агентов.

Живой пример [different-ai/openwork](https://github.com/different-ai/openwork)

👉 Как применить: не заменять им Hermes, а разобрать как источник интерфейсных решений для Hermes Desktop — единый каталог возможностей, поиск назначенных инструментов, запуск через одну точку и границы рабочего пространства. Если найдётся конкретно лучший сценарий, перенести его отдельно, без второго параллельного контура.

В X снова подняли ECC — набор практик уже поддерживает Hermes

Что случилось свежий пост в X 2 августа снова привлёк внимание к ECC. Сам проект не новый: репозиторий создан в январе, но обновлялся в последние сутки и уже имеет отдельную цель установки для Hermes. Сейчас в дереве 894 файла SKILL.md, 67 файлов агентов и 94 команды; часть SKILL.md — переводы и варианты, поэтому это не число уникальных навыков. У репозитория около 237 тыс. звёзд.

Живой пример [пост в X](https://x.com/DivyanshT91162/status/2083898529869943046) · [актуальный репозиторий ECC](https://github.com/affaan-m/ECC)

👉 Как применить: не устанавливать всё скопом. Сверить с нашими навыками только три блока: межагентная память, проверка безопасности изменений и обязательная самопроверка результата; забрать лишь отсутствующие приёмы.
