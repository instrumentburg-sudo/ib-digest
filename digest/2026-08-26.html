Apache Maka хранит работу агента как журнал событий

Что случилось Apache Maka поднялся в GitHub Trending на 543 звезды за день. Сообщения модели, вызовы инструментов, решения по правам и завершения пишутся в append-only журнал; графовые задачи запускаются в отдельных Git-worktree, а оценка хранит попытки, стоимость, длительность и причины сбоев. Проект пока ранний: готовой одобренной сборки нет, основной путь — сборка из исходников.

Живой пример https://github.com/apache/maka

👉 Как применить: Maka не ставить в прод. Сравнить его журнал восстановления и модель попыток с Hermes: особенно полезны явные причины остановки, неизменяемые записи запусков и повтор только сбойной ветки.

claude-obsidian превращает базу знаний в проверяемую транзакцию

Что случилось проект набрал 813 звёзд за день в GitHub Trending. Внутри 15 навыков для загрузки, поиска и проверки заметок; параллельные агенты возвращают только черновики, а один оркестратор применяет изменение после проверки SHA-256. При конфликте файл не перезаписывается молча, операция откатывается из журнала.

Живой пример https://github.com/AgriciDaniel/claude-obsidian

👉 Как применить: взять не весь плагин, а контракт записи для нашей Obsidian-памяти: preview → hash approval → одна атомарная запись → проверка ссылок. Это снижает риск, что два агента одновременно испортят одну заметку.

Локальный Qwen 35B на Raspberry Pi работает с 745-страничным руководством

Что случилось CarWatch набрал 81 балл и 15 комментариев на Hacker News на момент сбора. Автор запускает Qwen3.6-35B-A3B в квантизации 14,3 ГБ на Raspberry Pi 5 с 16 ГБ памяти: 3,5 токена/с при генерации и больше 25 токенов/с на входе. Ассистент отвечает по 745-страничному руководству с указанием страниц; чтение реального OBD пока проверено только на имитаторе.

Живой пример https://github.com/ThinkOffApp/CarWatch

👉 Как применить: проверить тот же принцип на руководствах по генераторам и компрессорам. Не тащить модель на каждый пост: один локальный сервер, поиск по PDF с цитатой страницы и честный отказ, если инструкции в документе нет.
