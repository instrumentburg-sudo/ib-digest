Снова всплыл правильный шлюз для длинных задач Claude Code

Что случилось свежая публикация в X вернула внимание к майскому демонстрационному репозиторию Anthropic — это не новый релиз. Полезная часть: все критерии по умолчанию имеют статус FAIL, отдельный оценщик без Write/Edit проверяет результат в свежем контексте, а передача между сессиями идёт через PROGRESS.md и git.

Источник свежая публикация — https://x.com/gippp69/status/2086741147611758804

Живой пример репозиторий — https://github.com/anthropics/cwc-long-running-agents

👉 Как применить: формализовать этот шлюз для задач Hermes, где агент сейчас сам себя проверяет: исполнитель создаёт артефакт и доказательства, отдельный оценщик только читает и выдаёт PASS или NEEDS_WORK. Это дешевле повторной переделки после самопроверки в том же контексте.
